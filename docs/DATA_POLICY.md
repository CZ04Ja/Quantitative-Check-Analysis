# Data and publication boundary

This package is a local publication candidate, not proof of an upload. The owner has stated that outputs are approved for sharing. Raw client records, contacts, interviews, credentials and licensed vendor histories are still excluded.

Historical copies, later reproductions and synthetic examples are separate. Historical notebooks have outputs, attachments and machine metadata cleared; local account paths are replaced. This removes embedded outputs, not every possible sensitive source-code literal, so final review remains necessary.

No blanket license is applied to team, employer or third-party materials. Existing author credits and methodological warnings must remain. Later review code was developed with coding assistance and should not be described as original internship code or sole authorship of a team system.

Do not add raw data merely because the repository is private. For any excluded source, use a local path and retain its original rights and confidentiality restrictions.
